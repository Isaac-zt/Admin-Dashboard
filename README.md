# React + Vite

Built a responsive Admin Dashboard with an updated header and sidebar layout. Currently working on integrating interactive charts to display analytics and insights.

Elevate Admin Dashboard is a modern, responsive admin web application designed for managing business operations and tracking key performance metrics. It features:

📊 Data Analytics — Displays insights like total revenue, active users, total orders, and page views.

📈 Interactive Charts — Visualizes monthly revenue vs. expenses and sales distribution by category.

💬 User & Message Management — Allows monitoring of users, inventory, transactions, and messages.

🎨 Modern UI/UX — Built with a dark theme, gradient accents, and a clean layout for readability.

⚙️ Functional Navigation Sidebar — Includes pages for Dashboard, Analytics, E-Commerce, Inventory, and more.
